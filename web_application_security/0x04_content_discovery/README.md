# Web Application Security - Content Discovery
This directory contains flag files and documentation for web content discovery tasks using manual inspection techniques and tools like Gobuster and FFuf.
## Task Map
* `0-flag.txt` - Manual Discovery (sitemap.xml / robots.txt)
* `1-flag.txt` - Manual Discovery (HTTP Response Headers)
* `4-flag.txt` - Directory Brute-Forcing (Gobuster dir mode)
* `5-flag.txt` - DNS Subdomain Enumeration (Gobuster dns mode)
* `6-flag.txt` - Subdomain Fuzzing (FFuf)
* `7-flag.txt` - Fuzzing Endpoints (Gobuster fuzz mode)
