# Web Application Forensics
This directory contains forensic analysis scripts for analyzing system and web application logs (`auth.log`, `dmesg`).
## Tasks
* `0-service.sh`: Identifies the service used by attackers.
* `1-operating.sh`: Extracts target system OS details.
* `2-accounts.sh`: Identifies the compromised user account.
* `3-ips.sh`: Counts distinct attacker IP addresses.
* `4-firewall.sh`: Counts added firewall rules.
* `5-users.sh`: Lists created user accounts.
